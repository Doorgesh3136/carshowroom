Sign in

Use a GitHub access token for the website repository.

How do I get a token?
  1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens.
  2. Press Generate new token. Give it a name like "V8 stock admin" and an expiry date.
  3. Under Repository access, pick Only select repositories and choose the website repository.
  4. Under Permissions, set Contents to Read and write.
  5. Generate it, copy it, and paste it here. Treat it like a password.
